## Search & answers

- 🔍 **Web search** — 100+ sites across 13 categories, merged and weighted by
  category ([details](/docs/search))
- 📝 **Article preview** — extract, cite in APA, and summarize articles, PDFs,
  YouTube and URLs before you read them ([details](/docs/reader))
- 🤖 **Any model** — Claude, GPT, Gemini, Grok, Llama, DeepSeek, or your own
  OpenAI-compatible endpoint ([details](/docs/chat))
- 📄 **File uploads** — ask questions about PDFs, DOCX, HTML, Google Docs and
  YouTube videos
- 📚 **Search history** — saved per account with memory, and a privacy mode
  that saves nothing
- ❓ **Follow-up questions** — generated alongside every answer
- 🗣️ **Voice** — speak a question (Whisper) and hear the answer (Kokoro or
  Deepgram)
- ⌨️ **Spotlight search** — <kbd>Ctrl</kbd> <kbd>Space</kbd> opens one bar over
  the app to jump to a past chat, a page, a setting or an action — or just ask
  ([details](/docs/chat#spotlight-search--ctrl-space))

## Content extraction

1. **Main content detection** — Mozilla Readability and Postlight Mercury plus
   100+ per-site adapters for article, author and date
2. **PDF to HTML** — headings, lists, footnotes, quotes and code blocks, with
   repeated headers stripped and page numbers preserved; optional OCR for
   scanned pages
3. **YouTube transcripts** — manual captions and auto-generated subtitles, with
   timestamps, no headless browser
4. **HTML standardization** — reading-mode HTML suited to archival and focused
   reading
5. **Citation extraction** — author, date, source and title, validated against a
   90,000-name database so organizations and people are formatted correctly

## REASON writing editor

- 📝 **Rich text editor** — a Tiptap-based, full-featured alternative to Google
  Docs ([details](/docs/reason-editor))
- 📂 **Nested document tree** — drag-and-drop organization, tabs, custom storage
  sources
- 🔍 **Full-text search** — find documents by title or content instantly
- ✨ **AI rewriting** — improve text in place
- 👥 **Team collaboration** — real-time editing via Yjs, with access rights
- 🔄 **View modes** — formatted, HTML, and Markdown
- 🛠️ **Find & replace** — with match highlighting
- 📥 **Google Docs** — import, export and share
- 💬 **Research quotes** — quotes saved while reading land in the document
- ⌨️ **Keyboard navigation** — shortcuts throughout

## Apps & integrations

- 🧩 **[Browser extension](/docs/browser-extension)** — AI tab manager, in-tab
  search, reader mode
- 🖥️ **[Desktop app](/docs/desktop-app)** — select text anywhere, press
  <kbd>`</kbd>, get an answer
- 🧠 **[VS Code extension](/docs/vscode-extension)** — research sidebar plus
  REASON for `.md` and `.docx`
- 🔌 **[MCP server](/docs/mcp-server)** — hand QwkSearch's tools to Claude
  Desktop or any MCP client
- 🌐 **[REST API](/docs/api)** — and a generated TypeScript client

## Platform

- **Open source** under the [PROSPER license](https://rights.institute/PROSPER)
- **[Self-hostable](/docs/self-hosting)** on Cloudflare Workers (D1, KV, R2) or
  locally
- **Private metasearch** via a self-hosted SearXNG proxy
- **[~20 reusable packages](/docs/packages)** — the search aggregator,
  extractors, LLM toolkit, chat UI and editor all work standalone
