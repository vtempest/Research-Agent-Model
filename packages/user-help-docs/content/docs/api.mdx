Everything the website does goes through a documented REST API you can call
yourself.

- **Base URL** — `https://qwksearch.com/api`
- **Interactive reference** — [/api/docs](/api/docs), rendered from the OpenAPI spec
- **Raw spec** — [/api/openapi](/api/openapi)

## Authentication

Requests work signed-out, with guest rate limits. To use your account's models,
history and storage, send your personal API key:

```http
Authorization: Bearer <your-api-key>
```

Find it under **Settings → Account** on your QwkSearch instance.

## TypeScript client

Rather than hand-writing fetch calls, use the generated client — it's built
from the same OpenAPI spec, so it stays in step with the API.

```bash
bun i qwksearch-api-client
```

```ts
import { client } from 'qwksearch-api-client';

client.setConfig({
  baseUrl: 'https://qwksearch.com/api',
  headers: { Authorization: `Bearer ${process.env.QWKSEARCH_API_KEY}` },
});
```

## Endpoints

### Search

| Method | Path | Purpose |
|---|---|---|
| `GET` | `/search/engines` | Every available engine, by category |
| `GET` | `/search/engines/status` | Which engines are enabled |
| `POST` | `/search/engines/status` | Update enabled engines |
| `POST` | `/search/engines/test` | Probe which engines are responding |
| `GET` | `/agent/search` | Meta-search via SearXNG |
| `GET` | `/agent/autocomplete` | Query autocomplete suggestions |
